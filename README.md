# Signs-n-$hine staging preview

This repository publishes a **public testing preview** from [jh1528/sns-web](https://github.com/jh1528/sns-web), branch `feature/careers-application`.

The GitHub Actions workflow checks out the source repository's feature branch and deploys its `website/` folder. This repository is separate from the live `sns-web` deployment.

Staging is publicly accessible. The careers page links to a real Google Form, so avoid submitting fake applicant data.
